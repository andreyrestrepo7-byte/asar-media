# asar-media

Imágenes públicas de **Somos ASAR** para Instagram. Las usan los agentes del coworking (Simón diseña, Lucas publica con Windsor.ai).

- `marca/`: logo y foto de perfil.
- `posts/AAAA-MM-DD-slug/`: diapositivas JPEG 1080 × 1350 de cada post.
- `herramientas/render.py`: plantilla de carruseles con la marca A.S.A.R.

Este repositorio es público: nunca subir facturas, datos de clientes ni archivos de la empresa.
